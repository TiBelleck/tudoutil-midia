# tudoutil-midia

Repositório técnico de mídia para publicação automática de posts aprovados (Instagram, via API oficial).

- Só contém as imagens e vídeos dos posts já aprovados pelo responsável.
- Os arquivos de cada lote ficam em `midia/AAAA-MM-DD_xxxxxxxx/` e são apagados depois de alguns dias.
- Não há código, dados pessoais nem segredos aqui.
